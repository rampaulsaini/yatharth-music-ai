# Android से शुरुआत — Yatharth Music AI 1.1

1. ZIP डाउनलोड करें।
2. Chrome में Google Colab खोलें।
3. `colab/Yatharth_Music_AI_v1_1_mobile.ipynb` upload/open करें।
4. Cells को ऊपर से नीचे चलाएँ।
5. GPU उपलब्ध हो तो ACE-Step real generation के लिए इस्तेमाल होगा।
6. अंतिम cell में temporary `YATHARTH_PUBLIC_URL` मिलेगा।
7. Frontend `frontend/app.js` में `API_BASE` को उस URL पर सेट करें।
8. मोबाइल में frontend खोलें।
9. Prompt → Generate → task polling → audio player.

Free GPU/session availability बदल सकती है; यह zero-budget experiment है, guaranteed production hosting नहीं।
