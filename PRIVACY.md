# Privacy Notice — Draft

**Status:** Draft for the development project. Review and update this notice before collecting personal data or launching a public commercial service.

## What the current app stores

The current backend keeps generation tasks in process memory. The browser stores local song-history metadata in local storage. Demo mode does not require an account.

A future production deployment may process prompts, lyrics, generation metadata, account information, technical logs, and generated audio. The exact data collected must be documented before launch.

## Purpose

Data should be processed only as necessary to provide music-generation features, maintain security, diagnose failures, improve reliability, and meet applicable legal obligations.

## Third parties

A production deployment may send generation requests to an AI music engine such as ACE-Step. Operators must review the model/provider license and privacy terms before sending user content.

## User content

Do not submit passwords, API keys, payment-card information, or other unnecessary sensitive information into prompts or lyrics.

## Retention and deletion

The current in-memory task store is not durable. Production retention periods, account deletion, generated-audio deletion, backups, and log retention must be defined before launch.
